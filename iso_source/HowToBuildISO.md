# Build Umbra Linux ISO from source

> [!NOTE]  
> Current release will be available in UmbraLinux/iso_source/ but past releases will be in this directory in form of git submodules.
> When you are git cloning the repo submodules (older versions) can be installed using ```git submodule update --init --recursive``` command

**We are currently exploring possibility to provide live iso with just cli and nothing else to enable users to compile/install via our packagemanager packages that they want, sort of gentoo/arch way of doing things but this option will be just for power users.**
